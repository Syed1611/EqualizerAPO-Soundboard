APO Soundboard v0.6.3 build checks
=================================

- APOSoundboard_v0.6.3.dll: PE32+ x86-64 Windows DLL.
- APOSoundboardController.exe: PE32+ x86-64 Windows GUI executable.
- DLL export table contains VSTPluginMain.
- Clang static analyzer reported 0 diagnostics for plugin.c.
- Clang static analyzer reported 0 diagnostics for controller.c.

Hotkey-capture change:
The controller unregisters its own global hotkeys before listening for a new
binding and restores them after accept/reject/cancel. This prevents a key being
tested for a new pad from simultaneously firing the pad that already owns it.
A WM_HOTKEY guard is also present during capture.

Slider change:
Volume is quantized to 0.5 percentage-point values. Pitch is stored in signed
half-semitone units (-48..+48), corresponding to -24.0..+24.0 semitones.
Legacy config pitch integers are multiplied by two during load.

The existing v0.6.2 stability hardening and resource diagnostics are unchanged.
