APO Soundboard v0.8.7 audit
============================

Focused diagnostics-page rendering fix based on v0.8.6.

Checks performed:
- clang --analyze: controller.c: no diagnostics
- clang --analyze: plugin.c: no diagnostics
- controller strong warning build: no warnings
- plugin strong warning build: only two benign unused helper warnings in winlite.h
- x64 PE output verified
- VSTPluginMain export verified

UI fix notes:
- page-specific controls are always hidden/shown explicitly on layout
- inactive-page pixels are cleared while both page control sets are hidden
- parent and active child windows are synchronously repainted after a page switch
- diagnostics uses 3 columns at normal desktop widths, 2 at narrower widths
- diagnostic cards are clamped to the visible client area

The v0.8.6 WinMM-compatible monitor backend is unchanged.
