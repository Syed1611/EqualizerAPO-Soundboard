LLVM clang + lld-link for Windows x64. In src/:

clang -target x86_64-pc-windows-msvc -O3 -ffreestanding -fno-stack-protector -fno-builtin -c plugin.c -o plugin.obj
lld-link /dll /subsystem:windows /entry:DllMain /nodefaultlib /machine:x64 /export:VSTPluginMain /out:APOSoundboardScratch_v0.9.4.dll plugin.obj
clang -target x86_64-pc-windows-msvc -O3 -ffreestanding -fno-stack-protector -fno-builtin -c controller.c -o controller.obj
lld-link /subsystem:windows /entry:entry /nodefaultlib /machine:x64 /out:APOSoundboardScratchController.exe controller.obj

For offline DSP tests, compile each test file in tests/ with clang -O2 -I.
and -lm on Linux/macOS (C source uses fixture paths under /mnt/data; edit those
if running on another computer). All DSP algorithms are in scratch_dsp.h.
