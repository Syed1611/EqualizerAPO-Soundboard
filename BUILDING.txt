Rebuilding APO Soundboard v0.2 x64
===================================

Required:
- LLVM clang targeting x86_64-pc-windows-msvc
- lld-link

From the src directory:

clang -target x86_64-pc-windows-msvc -O2 -ffreestanding -fno-stack-protector -fno-builtin -c plugin.c -o plugin.obj
lld-link /dll /subsystem:windows /entry:DllMain /nodefaultlib /machine:x64 /export:VSTPluginMain /out:APOSoundboard_v0.2.dll plugin.obj

clang -target x86_64-pc-windows-msvc -O2 -ffreestanding -fno-stack-protector -fno-builtin -c controller.c -o controller.obj
lld-link /subsystem:windows /entry:entry /nodefaultlib /machine:x64 /out:APOSoundboardController.exe controller.obj

Static checks:
file APOSoundboard_v0.2.dll APOSoundboardController.exe
llvm-objdump -p APOSoundboard_v0.2.dll

Expected:
- Both files are PE32+ x86-64.
- DLL export table contains VSTPluginMain.
- VST flags include replacing + editor support.
- Editor dispatcher implements effEditGetRect/Open/Close/Idle for Equalizer APO.

The source has no JUCE, Steinberg SDK, MSVC runtime, or third-party binary dependency.
