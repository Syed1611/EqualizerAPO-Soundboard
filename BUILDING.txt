Build APO Soundboard v0.8.8 (x64 Windows PE, no Steinberg SDK):

Requirements: clang, lld-link with MSVC target support. From this folder's src:

clang -target x86_64-pc-windows-msvc -O3 -ffreestanding -fno-stack-protector -fno-builtin -c plugin.c -o plugin.obj
lld-link /dll /subsystem:windows /entry:DllMain /nodefaultlib /machine:x64 /export:VSTPluginMain /out:APOSoundboard_v0.8.8.dll plugin.obj
clang -target x86_64-pc-windows-msvc -O3 -ffreestanding -fno-stack-protector -fno-builtin -c controller.c -o controller.obj
lld-link /subsystem:windows /entry:entry /nodefaultlib /machine:x64 /out:APOSoundboardController.exe controller.obj

Both binaries manually resolve Win32 functions via winlite.h, so their import
sections may be unusually small/empty. The DLL implements a VST2 ABI subset.
