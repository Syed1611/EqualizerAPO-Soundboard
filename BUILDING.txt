# Scratch Edition v1.1 — freestanding Windows x64 build

The soundboard has no external audio or C runtime dependency. Build from `src/` with clang targeting Windows x64 and LLD, keeping the included resource files beside the original source folder:

```sh
clang -target x86_64-pc-windows-msvc -O3 -ffreestanding -fno-stack-protector -fno-builtin -c controller.c -o controller.obj
lld-link /subsystem:windows /entry:entry /nodefaultlib /machine:x64 /out:../APOSoundboardScratchController.exe controller.obj ../AppIcon.res ../ControllerManifest.res
clang -target x86_64-pc-windows-msvc -O3 -ffreestanding -fno-stack-protector -fno-builtin -c plugin.c -o plugin.obj
lld-link /dll /subsystem:windows /entry:DllMain /nodefaultlib /machine:x64 /export:VSTPluginMain /out:../APOSoundboardScratch_v1.1.dll plugin.obj ../PluginVersion.res
```

- `ControllerManifest.res` embeds `Controller.asInvoker.manifest` as `RT_MANIFEST`, resource type 24, ID 1. The EXE must remain a GUI subsystem executable, not a console program.
- Controller, DLL and IPC must agree on `BUILD_VERSION=110000`, protocol 3, and `Scratch_v12s` pipe. The `CtrlR20` window class and `v102s` mutex are intentionally retained for compatible R19/R20 DLL launch. This is independent of settings format, which stays `config_scratch_v12.bin`.
- Validate resources (`objdump -p`), exports (`VSTPluginMain`), and SHA256 checksums after building.
- Offline C test suite from release root:

```sh
for f in tests/test_*.c; do n=$(basename "$f" .c); clang -O2 -fdeclspec -I. -Wno-incompatible-library-redeclaration -Wno-ignored-attributes "$f" -lm -o "/tmp/$n" && "/tmp/$n" || exit 1; done
python tests/test_open_panel_r20.py
```

Optional host patch (`host-integration/EqualizerAPO-OpenPanel-direct.patch`): **Not** built by these commands. It requires the matching Equalizer APO Qt/MSVC project. See `host-integration/README.md`. No upstream executable or installer is bundled or overwritten. GPL-2.0-or-later distribution requirements apply to a modified Equalizer APO Editor.

Run `python tests/test_r20_full_pipeline.py` for the neutral-prefix and finite-output controller comparison and `python tests/test_r21_pitch.py` for the neutral and alias comparison.
