Scratch Edition v0.9.8 (freestanding Win64 C, LLVM/LLD)

Run in the src directory:
clang -target x86_64-pc-windows-msvc -O3 -ffreestanding -fno-stack-protector -fno-builtin -c plugin.c -o plugin.obj
lld-link /dll /subsystem:windows /entry:DllMain /nodefaultlib /machine:x64 /export:VSTPluginMain /out:APOSoundboardScratch_v0.9.8.dll plugin.obj
clang -target x86_64-pc-windows-msvc -O3 -ffreestanding -fno-stack-protector -fno-builtin -c controller.c -o controller.obj
lld-link /subsystem:windows /entry:entry /nodefaultlib /machine:x64 /out:APOSoundboardScratchController.exe controller.obj

Protocol-v3 / Scratch pipe v7: DLL and controller from the same version must be installed together.
No third-party runtime libraries required.
Offline test example, from package root:
clang -O3 -I . tests/test_fidelity.c -lm -o test_fidelity && ./test_fidelity
