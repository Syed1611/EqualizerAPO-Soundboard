Experimental Scratch Edition v0.9.6 (Win64 freestanding source)

From src/: use LLVM clang/lld-link targeting x86_64-pc-windows-msvc.

clang -target x86_64-pc-windows-msvc -O3 -ffreestanding -fno-stack-protector -fno-builtin -c plugin.c -o plugin.obj
lld-link /dll /subsystem:windows /entry:DllMain /nodefaultlib /machine:x64 /export:VSTPluginMain /out:APOSoundboardScratch_v0.9.6.dll plugin.obj

clang -target x86_64-pc-windows-msvc -O3 -ffreestanding -fno-stack-protector -fno-builtin -c controller.c -o controller.obj
lld-link /subsystem:windows /entry:entry /nodefaultlib /machine:x64 /out:APOSoundboardScratchController.exe controller.obj

The VST2-compatible ABI subset and DSP are freestanding (no CRT/DLL runtime
requirements beyond Win32 system facilities). Large FFT/temp work arrays
are in heap-owned voice objects to avoid Windows __chkstk dependencies.

Native offline DSP tests from release folder with a C compiler:
clang -O3 -I . tests/test_motion_regression.c -lm -o test_motion_regression
./test_motion_regression
clang -O3 -I . tests/test_spectral_freeze.c -lm -o test_spectral_freeze
./test_spectral_freeze
clang -O3 -I . tests/test_freeze_regression.c -lm -o test_freeze_regression
./test_freeze_regression
clang -O3 -I . tests/test_live_pitch.c -lm -o test_live_pitch
./test_live_pitch

Other existing tests/test_scratch.c can run if voice input fixture exists.
Tests producing sample files may need output path edits for other hosts.
