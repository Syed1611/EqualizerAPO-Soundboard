Experimental Scratch Edition v0.9.7 (Win64 freestanding C source)

Requires LLVM clang + lld-link with x86_64-pc-windows-msvc target.
From src/ (or adjust paths):

clang -target x86_64-pc-windows-msvc -O3 -ffreestanding -fno-stack-protector -fno-builtin -c plugin.c -o plugin.obj
lld-link /dll /subsystem:windows /entry:DllMain /nodefaultlib /machine:x64 /export:VSTPluginMain /out:APOSoundboardScratch_v0.9.7.dll plugin.obj

clang -target x86_64-pc-windows-msvc -O3 -ffreestanding -fno-stack-protector -fno-builtin -c controller.c -o controller.obj
lld-link /subsystem:windows /entry:entry /nodefaultlib /machine:x64 /out:APOSoundboardScratchController.exe controller.obj

Build the DLL and controller together; both communicate using a separate
Scratch Edition v6 named pipe, isolated from earlier builds and v0.9.0.
No third-party runtime DLLs are bundled. Large FFT and OLA buffers live
in heap-allocated voice objects rather than on the worker stack.

Native offline DSP tests: clang -O3 -I . tests/<testname>.c -lm -o <testname>.
See TESTING.txt for test cases and Windows verification steps.
