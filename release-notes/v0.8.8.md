# Changelog

## v0.8.8

### Added
- Pad hover/selection/playback states; hotkey-based selection without focus theft.
- Red waveform cursor guide, separate from blue playback playhead.
- Per-pad Auto Sweep triangle LFO with animated live pitch slider.
- Oscillator speed and depth buttons plus editable value fields.
- Per-pad oscillator state in config v11; saved/restored window coordinates.
- Hover feedback for custom sliders.

### Fixed / Hardened
- Monitor ownership released when the current audio source falls idle.
- Monitor queue allows up to six bounded WinMM buffers.
- VST worker start guarded against a still-alive previous worker.
- Restore saved size/position without minimized-state dimensions.

### Notes
- Independently adjustable playback speed/time-stretching intentionally omitted.
- Windows/Equalizer APO runtime validation required before marking stable.

For the older history, see the repository changelog through v0.8.7.
