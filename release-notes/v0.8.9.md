# v0.8.9 test-build changelog

## Improved
- Dark panel grouped as Volume-left and Pitch/Auto Sweep-right.
- LFO rate and depth editing controls repositioned in non-overlapping rows.
- Consistent owner-drawn interaction states for key action buttons.
- Compact single-line bottom status area with ellipsis.
- Prevent redundant show/hide operations on each window resize.
- Reconcile stale PLAYING indicators when the VST DSP stops delivering audio.
- Detect Ogg Opus container to explain unsupported Media Foundation decodes.

## Outstanding
- Standalone native Vorbis and Opus decoding is not yet included.
- Windows hardware playback, host Apply/reconnect, and DPI/runtime UI behavior require device testing.
