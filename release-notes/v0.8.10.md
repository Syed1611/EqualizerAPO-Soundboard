# v0.8.10 test-build changelog

## Fixed
- Removed top/bottom-only button focus lines; owner-drawn actions now paint
  a complete keyboard-focus outline instead of two horizontal streaks.
- Integrated Auto Sweep, Speed and Depth into the same charcoal control panel
  as Pitch, with matched dark inputs/buttons and aligned text.
- Replaced non-editable/awkward numeric fields with restricted decimal entry.

## Added
- Speed and Depth accept typed numeric values, one decimal point and up to
  two fractional digits. Enter/focus change commits; Esc reverts; Ctrl+A selects.
- Explicit value rounding/clamping at commit time.

## Unchanged
- Volume remains exclusively on the left side of the panel.
- Audio engine, hotkeys, waveform, monitoring, and Diagnostics use v0.8.9 behavior.
- Native Vorbis/Opus decoding remains outstanding.
