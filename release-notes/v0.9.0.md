# APO Soundboard changelog

## v0.9.0 — Theme and text alignment

### Added
- Light/Dark theme toggle in the Tools menu, with persistent user preference.
- Dark surfaces for pad grid, waveform, status/diagnostics, edit controls and playback-device list.
- Optional native title-bar dark mode for supported Windows versions.

### Fixed / polished
- Owner-drawn button labels are now vertically and horizontally centered.
- Multiline pad content is measured and centered as a unit, rather than top-aligned.
- Native static labels use center-image alignment within their existing slots.
- Preserved existing pitch/volume/Auto Sweep panel layout.

### Compatibility
- Existing config v11 is unchanged. Dark-mode preference uses a separate
  one-byte file, avoiding modifications to the soundboard configuration.
- VST/controller protocol v3 and audio path unchanged.
- Unresolved: native Ogg Vorbis/Opus decoding.
